## ✨ Overview

**Better Teresa** is a community-driven, open-source initiative that brings the BetterLGU vision to the Municipality of Teresa, Rizal. It centralizes verified municipal data — budgets, infrastructure projects, ordinances, services, and government contacts — into a single, citizen-friendly interface.

> *An informed community is an empowered community.*

This project is **not** an official government website. It is independently maintained by volunteers who believe transparency should be the default, not the exception.

---

## 🎯 Project Vision

Our goal is to foster an informed and engaged community by providing a centralized, verified, and open-source interface for:

- 📋 Municipal services and official portals
- 📊 Budget disclosures, ordinances, and project status
- 🏛️ Government directories and elected representatives
- 🗂️ Searchable public records archive

---

## 🚀 Features

| Feature | Description |
| --- | --- |
| 🏛️ **Government Directory** | Contact information for municipal offices and elected officials, including the Sangguniang Bayan. |
| 🔍 **Transparency Dashboard** | Real-time access to budget disclosures, legislative ordinances, and project status updates. |
| 📂 **Public Records Archive** | Integrated search for verified government documents sourced from official archives. |
| 🌐 **Tourism Portal** | Curated, categorized directory of local attractions, dining, and landmarks. |
| 📱 **Bilingual Support** | English / Filipino (Tagalog) language toggle for civic accessibility. |
| 📈 **Local Statistics** | At-a-glance municipal figures — classification, founding year, and more. |
| ☀️ **Live Weather Widget** | Real-time local conditions powered by Open-Meteo. |

## 🧰 Tech Stack

- ⚛️ **Framework:** React 18
- ⚡ **Build Tool:** Vite
- 🎨 **Styling:** Tailwind CSS
- 🧩 **UI:** shadcn/ui + Lucide Icons
- 📡 **Data:** Open-Meteo API, official municipal archives
- 📐 **Design Pattern:** BetterLGU Open-Source Template (inspired by [BetterGov.ph](https://lgu.bettergov.ph))

## 📦 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MewSeiren/betterteresa.org.git
   cd betterteresa.org
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. Open the local URL printed by Vite in your browser.
